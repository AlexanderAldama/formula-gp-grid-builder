# formula-gp-grid-builder
The FormulaGP Grid Builder project is intended to enable players of the board game FormulaGP to simulate real Formula One seasons.

FormulaGPRandomGridBuilder.py allows players to generate random opponents for games of FormulaGP.

FormulaGPConditionalGridBuilder.py allows players to generate random opponents for games of FormulaGP with altered probabilities based on driver nationality, team nationality, and car speed.

These programs can be run in Visual Studio Code or any platform that can run Python code and has access to a terminal.
